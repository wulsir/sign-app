手語序 — 台灣手語語序練習
========================

使用方式（可雙擊開啟）
--------------------
直接雙擊 index.html，用 Edge 或 Chrome 開啟即可。
不需要安裝、也不需要本機伺服器。

請保持資料夾結構完整：
  index.html、app.js、data.js、order.js、styles.css、videos/

功能
----
- 語序、詞彙、九堂課、練習（認詞／排語序／閃卡）
- 進度匯出：JSON 備份、文字報告、CSV
- 歌曲：導向可公開分享的 YouTube 手語影片

影片來源：台灣手語線上辭典（國立中正大學）
語序轉換為教學示意，不是逐句翻譯器。
